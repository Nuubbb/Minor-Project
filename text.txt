
1. Backend
cd Surveillance-System
source venv/bin/activate      # venv already exists, Python 3.10
python app.py
Visit http://localhost:5001 in a browser → log in as Admin (admin/admin123) or Operator (sign up in-app).

2. Mobile app (Expo/React Native)
cd mobile
npm install
npx expo start
Before that, set mobile/src/config.ts's API_BASE_URL to your machine's LAN IP (currently 192.168.1.82, matching what Flask printed) — it's currently 127.0.0.1, which only works if Expo runs on the same machine as the backend. Then scan the QR code with Expo Go on your phone (same Wi-Fi network), or use the adb reverse USB path documented in SETUP.md if you don't want to depend on Wi-Fi.

To stop the backend I started

pkill -f "python app.py"

One thing worth flagging: mobile/src/config.ts defaults API_BASE_URL to 127.0.0.1, which won't work from a physical phone — you'll want to switch that to the LAN IP (or use the USB/adb reverse alternative) before testing on-device.
